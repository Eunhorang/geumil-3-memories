# 2026년 금일초 3학년의 추억

금일초등학교 3학년 우리 반의 3월부터 11월까지를 맑은 그림으로 다시 그린 웹사진전입니다.

- 주소: <https://eunhorang.github.io/geumil-3-memories/>
- QR 코드: `qr/사이트주소-QR.png`(인쇄용, 약 10cm) · `qr/사이트주소-QR.svg`
- A4 안내문: `qr/QR-안내문.pdf`(인쇄용) · `qr/QR-안내문.png`. 문구를 고치면 `qr/poster.html`을 바꾸고 `zsh tools/poster.sh`로 다시 뽑습니다. 그림 수와 달 범위는 빌드할 때 저절로 맞춰지니, 사진을 더하거나 뺀 뒤에는 `zsh tools/poster.sh`만 다시 돌리면 됩니다.

## 어떻게 만들었나

- 사진 속 촬영 일시(EXIF)를 읽어 달별로 나눴습니다.
- 그림은 이 맥(맥스튜디오)의 MLX-Serve에서 FLUX.2 klein 9B(`mlx-community/flux2-klein-9b-4bit`)로 바꿨습니다. 사진은 맥 밖으로 나가지 않습니다. 프롬프트 원문은 `tools/prompt-ko.txt`, 모델에 넣은 영어 번역은 `tools/prompt.txt`에 있습니다.
- 마음에 안 드는 장면은 `zsh tools/convert.sh --only <아이디> --seed <숫자>`로 다시 그립니다. 고른 씨앗은 `tools/config.json`의 `seeds`에 남습니다.
- 원본 사진은 위치 정보(GPS)를 지우고 긴 변 2560px로 줄인 뒤 비밀번호로 암호화해서(AES-256-GCM, PBKDF2 60만 회) `img/photo/`에 올립니다. 비밀번호를 모르면 저장소를 열어 봐도 원본을 볼 수 없습니다.
- 검색 엔진에 나오지 않도록 `robots.txt`와 `noindex`로 막아 두었습니다.

## 사진을 더할 때

1. 새 사진을 `금일초 3학년 학급 사진` 폴더에 넣습니다. 파일 이름을 행사 이름으로 바꿔 두면 그대로 제목이 됩니다(예: `학예회 단체사진.jpg`).
2. `사진 추가하기.command`를 두 번 누릅니다. 새 사진 찾기, 원본 잠그기, 그림으로 바꾸기, 전시 파일 만들기를 차례로 하고 마지막에 GitHub에 올릴지 묻습니다. Claude에게 "새 사진 추가해 줘"라고 해도 됩니다.
3. 올리고 1~2분 지나면 사이트에 반영됩니다.

새 달의 사진을 넣으면 그 달 칸이 저절로 생기고, 첫 화면·안내문 문구의 달 범위와 그림 수도 빌드할 때 맞춰집니다. 그 달 한 줄 소개는 `data/gallery.json`의 `months`에 적습니다.

### 이미 그림으로 된 파일을 넣을 때

`금일초 3학년 학급 사진/완성 그림` 폴더에 `2026-11-05 오카리나와 함께한 날.webp`처럼 파일 이름 앞에 날짜를 붙여 넣습니다. 그림 파일에는 촬영 날짜가 없어서 이름에서 읽고, 날짜 뒤 글자가 제목이 됩니다. 다시 그리지 않고 받은 그림을 그대로 걸며, 원본 사진이 없으니 크게 보기 창에 '원본 사진' 단추가 나오지 않습니다. 넣은 뒤에는 `사진 추가하기.command`를 똑같이 실행합니다.

### 사진을 뺄 때

`data/gallery.json`에서 그 사진 항목을 지우고, 다시 들어오지 않게 `tools/config.json`의 `skip`에 파일 이름을 적습니다. 다음 빌드 때 그 사진의 그림과 잠긴 원본 파일은 지워지고, 변환 작업 파일은 `_work/removed/`로 옮겨집니다.

## 제목과 설명 고치기

`data/gallery.json`에서 사진마다 `title`(제목), `event`(행사 이름), `alt`(그림 설명)를 고치면 됩니다. GitHub 웹에서 바로 고쳐도 반영됩니다. 달마다 붙는 한 줄 소개는 `months`에 있습니다.

## 원본 비밀번호 바꾸기

1. `zsh tools/set-password.sh`를 실행하고 새 비밀번호를 두 번 입력합니다. 비밀번호는 이 맥의 키체인에만 저장됩니다.
2. `node tools/build.mjs --rekey`로 원본 전체를 새 비밀번호로 다시 잠급니다.
3. GitHub에 올립니다.
